FluentFlyouts-Free es una versión moderna e independiente de FluentFlyouts compilada directamente a partir del código fuente oficial, trayendo la experiencia premium completa a tu escritorio.

La interfaz de usuario se integra perfectamente con Windows 11, brindándote una experiencia ininterrumpida, limpia y de aspecto nativo al controlar tus elementos multimedia, teclas de bloqueo y más. Cuenta con animaciones fluidas, se adapta a los temas de color de tu sistema e incluye un conjunto completo de opciones de personalización sin ninguna restricción de licencia de la tienda.

## Características ✨
- **Panel de Audio:** Muestra la portada, el título, el artista y controles multimedia completamente interactivos.
- **Panel "A continuación":** Muestra qué canción sigue cuando termina la pista actual.
- **Panel de Teclas de Función:** Muestra el estado en tiempo real de las teclas de bloqueo (Bloq Mayús, Bloq Num, Bloq Despl) de un vistazo.
- **Widget de la barra de tareas:** Muestra información multimedia activa directamente en la barra de tareas de Windows.
- Compatibilidad total con fuentes personalizadas (incluyendo las favoritas de Discord Nitro como *Monkey Bars*).
- Núcleo optimizado basado en la arquitectura de .NET para garantizar un consumo mínimo de memoria RAM.
- Soporte nativo para los efectos de desenfoque Mica y Acrylic de Windows y posiciones de paneles personalizables.
- Funciona de manera autónoma como un archivo ejecutable independiente.

## Cómo instalar 📥
### Usando el Instalador Independiente (Setup)
1. Dirígete a la pestaña de [Releases](https://github.com) de nuestro repositorio.
2. Descarga el archivo ejecutable más reciente **`FluentFlyouts_Setup.exe`**.
3. Ejecuta el instalador en tu sistema Windows y sigue los sencillos pasos del asistente.

## Sostenibilidad y Código Abierto 💰
FluentFlyout es y siempre será gratuito y de código abierto. La versión oficial disponible en la Microsoft Store funciona como una opción de pago para apoyar el mantenimiento del núcleo original, mientras que el código fuente permanece abierto para todos.

Esta versión funciona como una bifurcación (fork) abierta e independiente compilada directamente desde el código fuente de GitHub, brindándote acceso completo a todos los parámetros de diseño de forma totalmente gratuita.
