The UI seamlessly blends in with Windows 11, providing you an uninterrupted, clean, and native-like experience when controlling your media, lock keys, and more. It features smooth animations, pairs with your system's color themes, and includes a full suite of customization options without any store licensing restrictions.

## Features ✨
- **Audio flyout:** Displays Cover, Title, Artist and full responsive media controls.
- **"Up Next" flyout:** Shows what track is coming up next when a song ends.
- **Lock Keys flyout:** Displays the real-time status of lock keys at a glance.
- **Taskbar widget:** Shows active media info directly on the Windows taskbar.
- Full compatibility with custom fonts (including Discord Nitro fonts like *Monkey Bars*).
- Core built on optimized .NET architecture for near-zero memory footprint.
- Native Windows Mica/Acrylic blur support and customizable flyout positions.
- Stands as a fully featured, independent, standalone executable.

## How to install 📥
### Using the Standalone Setup Installer
1. Navigate to our repository's [Releases](https://github.com) tab.
2. Download the latest pre-compiled **`FluentFlyouts_Setup.exe`**.
3. Run the installer executable on your Windows machine and follow the simple setup steps.

## Sustainability & Open Source 💰
FluentFlyout is and always will be free and open-source. The official version available on the Microsoft Store acts as a paid tier to support the original core maintenance, while the source code remains open to everyone. 

This build functions as an independent, open fork compiled directly from the GitHub source, giving you full access to all design parameters completely free of charge.
